# Tutorials

These tutorials are a progressive Python course. Each chapter introduces one
analysis decision through short, reusable snippets. Complete runnable studies
belong in the repository examples; the tutorials concentrate on the laddu API,
the mathematics it implements, and the choices an analysis must make.

1. {doc}`data-io` — read, construct, transform, bin, and write event data.
2. {doc}`quantum-numbers` — describe particles, reaction channels, frames, and angular momentum.
3. {doc}`quantum-rules` — validate decays and enumerate allowed partial waves.
4. {doc}`generating-mc` — generate model-independent phase-space Monte Carlo.
5. {doc}`expressions` — build symbolic kinematics, amplitudes, and models.
6. {doc}`polarized-photoproduction` — assemble a more involved helicity model.
7. {doc}`modeled-mc` — weight or unweight phase space with a model.
8. {doc}`fitting` — fit a model to unbinned event data and inspect the result.
9. {doc}`binned-fits` — fit independent model parameters across bins of event data.
10. {doc}`likelihoods` — choose normalized, extended, and regularized objectives.
11. {doc}`simultaneous-fits` — share parameters across several datasets.
12. {doc}`coupled-channel` — share resonance parameters across reaction channels.
13. {doc}`execution` — choose local, compiled, GPU, and MPI execution only when needed.
14. {doc}`cross-sections` — turn fitted intensities and efficiencies into cross sections.
